# Setmates — MVP Specification (Milestone 1)

This repository implements the Milestone 1 MVP for Setmates:

- email/password auth
- private groups with six-character join codes
- workout logging with exercise kinds and per-kind set rows
- last-performance placeholders and deltas
- custom exercises shared within a group
- a partner feed of finished workouts only
- estimated 1RM and PR tracking

The schema, RLS rules, RPC signatures, metric rules, and milestone definitions match the
problem statement used for this task.
